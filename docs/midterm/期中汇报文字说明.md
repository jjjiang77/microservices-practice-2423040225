# 商小淘期中汇报文字说明

## 项目名称与主要用途
商小淘是面向浙江工商大学学生的校园二手交易课程项目，为教材、电子产品与生活闲置物品提供校内发布、浏览和面交交易的后端基础。

## 当前完成的功能和技术工作
当前实现用户注册与查询、学号唯一性校验、商品发布与详情、分页与多条件筛选、审核上架、下架及购买后标记已售。业务规则包含价格区间0.01至2000元、信用分门槛60分、未售出同标题商品重复发布限制、自购限制及商品状态校验。

后端使用 Java 25、Spring Boot 4.0.7、Spring MVC、Spring Data JPA 和 MySQL。按用户、商品、购买入口拆出三个服务，利用 Nacos Discovery 获取实例地址，再通过 RestTemplate 发起同步HTTP调用。配置连接超时3秒、读取超时5秒，区分资源不存在与依赖不可用。Docker Compose 编排三个业务服务、MySQL和Nacos，配置本机端口、网络和持久卷。当前仍共用一个数据库，购买入口不保存独立订单。

2026年11月9日以127.0.0.1访问并完成14项HTTP检查：三个健康检查、卖家与买家查询、商品发布、重复发布拦截、价格超限拦截、审核、组合筛选、自购拦截、跨服务购买、重复购买拦截和已售状态查询全部达到预期。新增一条“期中验收”演示商品。原始结果保存在evidence/verification.json，可通过scripts/verify-midterm.py重新执行。此结果不代表完整自动化测试、故障恢复或并发测试通过。

本次统一services/开发入口，增加根Maven聚合配置，修正商品服务名称和组合筛选逻辑，并将健康检查默认地址改为与Compose绑定一致的127.0.0.1。此前localhost的404不能证明个人项目故障，该结论现已纠正。

## 问题、未完成部分与后续计划
当前无前端工程，仍以HTTP接口验收。学号注册不等于校园身份认证，尚无登录凭证及完整操作授权。购买只把商品置为SOLD，尚无订单、支付、取消和确认交割。数据库未按服务独立，旧测试仍需按新服务边界迁移。并发购买、注册竞争、负载均衡、故障恢复及分布式一致性尚未完成验收。

近期先迁移测试、补充请求校验和异常规范，形成可重复执行的验收基线。随后开发浏览、详情、发布和我的商品页面，接入登录鉴权并由令牌推导操作人。再实现订单持久化、状态机、幂等与并发控制。服务治理按课程内容逐步引入Gateway、OpenFeign与LoadBalancer，之后评估Resilience4j和Micrometer Tracing加Zipkin。聊天、帖子关联商品和小法庭作为后续扩展，每项均以实际实现和验收结果更新进度。
